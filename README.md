OpenRecipeColl -- The Open Cookbook

This repository collects recipe submissions for our community cookbook.
Every home chef keeps a personal branch named after themselves (for example
chef-ana) and groups their recipe folders into commits on that branch.

Each recipe lives in its own folder under recipes/, named after the recipe
with lowercase words separated by hyphens. The submission template that
shows what a finished recipe folder must look like is
recipes/examples/example-recipe.
